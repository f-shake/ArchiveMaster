# 代码复核记录

本目录保存 ArchiveMaster 的独立复核（代码审查）报告。报告只记录问题与判定，不代表已经修复；修复在对应的开发轮次里进行，并在报告中更新状态。

## 约定

- 文件名：`YYYY-MM-DD-<范围>.md`，例如 `2026-10-24-full-repo-review.md`。
- 每条问题包含：位置（相对路径 + 行号）、判定（已核实 / 已核实（逻辑） / 子代理 / 未复核）、机制、后果、修复方向。
- 行号以报告记录的基线提交为准；后续代码变动后可能漂移，需重新核对。
- 报告落盘后不追改历史结论；新一轮复核新建文件，并在下表追加一行。
