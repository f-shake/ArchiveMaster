# 照片标签搜索

- 工具 ID：`photoTagging.photoTagSearcher`
- 模块：照片标签工具（`photoTagging`）
- 准备阶段：无
- 准备阶段会写文件：否
- 提供条目级结果：否（结果见 notes）

根据关键词，查找指定标签的图像

## 配置模板

```json
{
  "TagFile": null,
  "RootDir": null,
  "UseWrapPanel": false
}
```

## 配置字段

| 字段 | 类型 | 默认值 |
| --- | --- | --- |
| `TagFile` | String | `null` |
| `RootDir` | String | `null` |
| `UseWrapPanel` | Boolean | `false` |
